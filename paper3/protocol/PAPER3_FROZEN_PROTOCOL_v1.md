## Core Question

Which task/stage-conditioned brain-state transitions are stable enough to be treated as reproducible empirical objects?

This paper does not try to rescue CWP after Paper 2. It asks a more basic question:

```text
Are ENCODE -> MAINTAIN and MAINTAIN -> PROBE transition vectors repeatable?
```

## E2 - Transition Reliability

Primary E2 estimand:

```text
cosine_similarity(mean transition vector split A, mean transition vector split B)
```

Transition vector:

```text
T = S_target - S_source
```

Primary conditions:

```text
ENCODE -> MAINTAIN
MAINTAIN -> PROBE
```

E2 computes:

```text
within-run odd/even split-half reliability
cross-run same-subject reliability where multiple runs exist
same-transition similarity
different-transition null similarity
same-minus-different contrast
```

## Success Criterion

Paper 3 E2 supports reproducibility only if:

```text
same-transition reliability > different-transition null
```

and this pattern is visible at the dataset level without relying on a single outlier subject.

## Claim Boundary

Allowed:

```text
Stage-conditioned transition vectors show / do not show repeatability under the current extraction.
```

Disallowed:

```text
CWP is validated.
CWP generalizes across datasets.
CWP is a natural neural primitive.
```
