# Frozen animal-level inference, sensitivities and falsification

## Inference and precision

Unit of inference is mouse, one equal weight per included animal. Print every mouse's effect, numerator LLs, actual unit-bin denominator, lab, QC/coverage and fit status. Never pool units, trials, sessions or probes as independent samples. Primary H0 is E[d_m]<=0 against positive mean B4−B1. Enumerate all2^n sign vectors s and use p=number(mean(s*d)>=observed mean(d))/2^n, including equality and observed assignment; no Monte Carlo correction for exhaustive enumeration. This is exact computation under independent sign-exchangeable **symmetric zero-centered mouse effects** at the null boundary, not assumption-free inference for an arbitrary population mean. Dependence/shared lab and asymmetry can invalidate that interpretation; n8 cannot empirically establish symmetry.

Before D, independent scientific review must record why sampling/independence/sign symmetry is scientifically defensible, without examining D effects. If not defensible, retain the planned statistic with a conditional-assumption label and withhold confirmatory interpretation; do not choose a favorable alternative test. No normality/symmetry pretest on D selects the inferential method. Development effects and any power discussion remain exploratory.

Bootstrap: 10,000 whole-mouse draws, n mouse IDs with replacement, arithmetic mean, PCG64 seed150101, two-sided95% percentile interval using linear quantiles. No trial/unit bootstrap as animal uncertainty. Report individual leave-one-mouse-out means, min/max, median/IQR, SD, sign proportions and lab means. Also report equal-lab mean and every leave-one-lab-out mean; these are dependence diagnostics, not independent-lab replication. Require >=4 final labs, no one lab>50% of primary mice for confirmatory labeling. Lab-block bootstrap with the same10,000 draws/seed150102 is a diagnostic sensitivity, not a replacement for the registered primary test; disclose its very small lab denominator.

Five secondary two-sided sign-flip p-values use |mean|, the same assumptions and all enumerated signs. Holm step-down across the **fixed five** contrasts at.05; unavailable comparison has p=1 and retains its slot. Secondary intervals use the same resampled mouse-index stream as the primary. Report raw and adjusted p for every contrast, including negative/mixed/unavailable. A secondary family uses its complete pre-D C-valid cohort; >=8 is required for any confirmatory secondary label,6–7 descriptive only,<6 unavailable. Do not change the primary cohort because a secondary fit fails.

The primary positive-claim conjunction is: >=8 primary-eligible Final mice, lab/assumption gates defensible, no critical integrity/numerical failure; mean gain>=.001 nats/unit-bin; 95%CI lower>0 and total width<=.01; primary one-sided p<=.05; >=ceil(.75n) mice have positive gain; every LOMO and leave-one-lab-out mean>0; every mandatory sensitivity below retains positive mean in its prespecified >=6 paired mice; N1/N2 descriptive disruption gates below pass and their assumptions/coverage are honestly reported. The gain/precision limits are prospective design resolutions (.001/.05=.02 nats/unit-second), not biological importance estimates or proof of power. Report CI width even when it fails. No post-hoc precision widening.

Verdicts per contrast: **SUPPORTED UNDER REGISTERED PREDICTIVE CRITERIA** only with the exact map below; **NOT SUPPORTED / MIXED** for a valid complete assessment that fails direction/significance/precision/robustness; **INCONCLUSIVE REQUIRED GATE** for missing essential source/numerics/assumptions/mandatory coverage. An all-negative valid primary with CI upper<0 is reported as negative predictive evidence. A null interval crossing0 is not equivalence or no biology. 6–7 mice is **DESCRIPTIVE ONLY**, even if every p is small. Broad biological/causal/real-time/primitive claims are always withheld.

## Four bounded surrogate reference suites

999 replicates/suite/mouse/authorized score partition, no new model fit, no recursively generated counts. RNG PCG64; seed=first8bytes big-endian SHA256 of UTF8 `P15-M1|150107|suite|subject|partition|replicate`, modulo2^64. No Python hash or dependent wall-clock seed. Preserve targets, unit identities, original partitions, native task covariates, validity masks and fitted state/scaler identity. Construct donor/surrogate history offline for negative-control evaluation, then run the same chronological causal predictor on that surrogate stream; these are destructive references, not real online predictors or replacement scientific datasets.

Draw schedule is fixed: N1 visits retained epochs in increasing numeric original trial ordinal, drawing one nonzero rotation each. N2/N3 visit strata lexicographically in the tuple order side(L,R,other),contrast(low,high),roleHalf(0,1),wheel(0,1 if present), drawing one nonzero cyclic donor offset per nonsingleton stratum; each stratum's epochs are in numeric original-trial order. N4 visits complete5trialblocks in increasing original block ordinal and draws one nonzero cyclic block offset. No draw is consumed for a skipped singleton/incomplete block. Each suite/mouse/role/replicate has its own fresh stream; all model contrasts reuse the identical resulting surrogate. This schedule and S07's separate stream prevent chunking or model evaluation order from changing realizations.

N1: for each epoch independently rotate its20-bin warm+score **multivariate**50ms count sequence by a uniformly sampled offset1..19; all units rotate together, each trial/unit total count preserved. Keep original target scoring counts and task/wheel fixed; recompute only history/state inputs. Compare original B4−B1 with the reference value. This breaks within-trial neural order/alignment but also neural/task alignment; it is not a conditional mechanistic null. For D, update its filter using surrogate past counts (never current original targets) while scoring original counts; document this intervention.

N2: permute whole multivariate history donor epochs within score-partition strata (stimulus side L/R/other; contrast low<=.25 vs high>.25; original trial ordinal first/second role half; pre-epoch wheel displacement above/below A/C median). Wheel magnitude is exactly `abs(w(epochStart−)−w((epochStart−.5)−))` using strict-past held encoder samples; its threshold is the ordinary median over valid **A/C** primary epochs, with ties placed in the lower stratum and >median in the upper. Side L/R means exactly that side has positive contrast and the other is absent/0; otherwise other; contrast magnitude=max(left,right) after source-absent-side conversion. Role half is cut at floor((original_role_start+original_role_stop)/2), before guards/exclusions. Stratum size>=2; donors are a random cyclic nonzero shift after numeric original-trial-ordinal sorting, preventing self-donors. Singletons excluded from **both** original and reference control exposures, not primary analysis. Require>=60% eligible primary score epochs covered and>=30 control epochs/mouse; no post-score coarsening. Keep original target/task/wheel. Tests reliance on same-trial history beyond measured coarse nuisance strata, with residual continuous nuisance imbalance disclosed.

N3: break measured wheel alignment by the same donor-epoch operator, stratifying only side/contrast/order half (omit wheel stratum); substitute wheel columns24–37 consistently in B1 and B4, keep neural/task inputs and targets. Compare original **B4 LL/Q** to wheel-disrupted B4 LL/Q; also report changes in B4−B1. Same coverage rule. This diagnoses wheel reliance/confounding, not independence from all movement; no required sign of gain change, and it cannot alone validate or falsify the primary history claim.

Compare original B4−B1 to reference; record aggregate pre-epoch rates/wheel imbalances from A/C features for donor-match limitations.

For each suite p_ref=(1+number(G_ref>=G_obs))/1000 using mean of same n complete control-mouse effects, with exposures identical for original/reference; Holm across fixed4suite reference p-values **separately for each registered contrast** (N3's registered statistic is its B4-LL reliance diagnostic, copied/labeled as that diagnostic rather than invented D/C wheel evidence). Reference p-values **are not exact population/conditional-null p-values** unless the relevant exchangeability/stationarity assumptions are justified prospectively. They never replace the primary mouse test. Every suite must terminate finitely; failure is preserved and cannot be labeled PASS. Do not use a successful surrogate suite to erase another failed suite.

If not, report history-order/conditional-alignment evidence as mixed/unavailable and withhold the robust positive primary label.
