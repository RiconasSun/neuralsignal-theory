### Whole-recording ALF access boundary

Native spikes.times/clusters files are whole-recording arrays. A future C-only worker must not silently load/decode/scan D timestamps/counts, perform D finite/order/range checks or consume D random streams just because it ultimately exports C. M1 authorizes none of these reads. Before any future Final C extraction, the source-preparation plan must demonstrate a C-scoped read path or obtain **separate explicit human authorization for a trusted local reader's exact low-level decoding scope**. Such authorization is not inherited from P13/P14 or from this protocol; without it, if extraction necessarily touches D neural content, STOP before C extraction. No independently held third-party data custodian is claimed and no cryptographic/offline-key architecture is introduced.

The trusted-reader route, if later explicitly approved, must expose only C-neural values to calibration/QC/scaling/model selection and preserve an extraction receipt; D-neural values, ranges, counts, finite-status summaries or D-derived QC must not influence or be exposed to that scientific role before the separate D assessment gate. Original source headers/provider curation metadata and task events may define partitions, but are not permission to inspect D neural values. New downstream numerical finite/order checks are limited to the currently authorized neural role. A D-only integrity failure discovered in the later authorized D batch makes that assessment incomplete; it cannot trigger C recalibration, unit replacement or D rerun. This is a prospective access/stop rule, not a claim that an unimplemented reader already enforces isolation.

Source identity checks: mouse/lab/date/session/eid/pid/probe must agree with fixed roster and provider metadata; cluster IDs integer and in-range, UUIDs unique, metrics rows correspond to cluster_id; map anatomy through native `channels[clusters.channels]`, not positional matching to another release. Current native atlas decides exact MOp membership; record every old/native disagreement. Layer-specific biological claims are not registered. If native mapping changes reduce units, retain attrition rather than substituting mouse/probe. The source atlas is uncertain near boundaries, not histological ground truth.

Observation: read AP file duration/sample rate/channel count/header size (no raw AP signal needed); require positive duration/fs, integer sample count and agreement of duration with fileSizeBytes/(2*nSavedChans*fs) within one sample. Original sync is finite, Nx2, strictly increasing in both columns. Map probe seconds to session seconds by the provider's piecewise-linear convention. Scored/warm-up epoch endpoints must lie within recorded support and the sync table's domain (no extrapolated epochs). **Currently authorized role** spikes are finite, nondecreasing and within support to one AP sample; nonfinite/unordered/mapping contradiction is an essential source error and stops that role's admission, not dropped/imputed. Do not inspect unapproved later-role values to pass this check. Do not infer support from first/last spike. Native events must have finite start,stim,goCue,feedback,end with start<=stim<=feedback<=end and goCue within trial before feedback; do not impose arbitrary cue/stim ordering. Require stim−.5>=start and stim+.5<=end and nonoverlapping original epochs. Real zero bins are observations; invalid support remains a separate mask.

Known saturation intervals are [start_sample,stop_sample), positive and inside recorded sample range, mapped through fs and the same probe sync. Primary exclusion uses any overlap with the complete warm+score epoch. Additional known bad/invalid annotation, if present in the same frozen native catalog, must be recorded with scope/clock and used; ambiguous clock is a source error rather than ignored. Missing other annotation means unknown artifact burden, not artifact-free or globally invalid. The primary curated sampling contract does not require absolute lossless-packet proof. Sensitivity dilation is fixed at ±10 ms and ±50 ms around known intervals; epochs are excluded accordingly, never recoded zero.

Provider label==1 and native MOp identity are upstream whole-session release curation, explicitly not new A/C-only QC. New physiology is computed **only inside valid A or C warm+score epochs**, with no ISI pair across epoch/gap boundaries: mean rate0.5–100 Hz inclusive, >=100 spikes, refractory fraction (# within-epoch adjacent ISIs<1 ms)/(# within-epoch adjacent ISIs) <=0.005; if denominator<99 reject. Require at least10 s valid exposure in each original chronological A/C quartile and rate>=0.1 Hz in each quartile; empty quartile rejects. All proposed eight units must meet these exact thresholds. Count events only in half-open intervals; no B/E/D-driven metric, drift check, normalization or downstream unit ranking.

Rank qualified units by refractory fraction ascending, A/C mean rate descending, UUID lexical. Select first8. Primary population is exactly8, never pads with bad units. This favors well-observed higher-rate units and is disclosed, with the fixed rate sensitivity below. Units5 and12/20 sensitivity sets are first U of the same A/C ranking; no score-based subset search. Five-unit sensitivity is mandatory;12/20 are capacity-conditional and reported unavailable if insufficient. Exclusion/attrition reports retain every candidate's reason and original role.

Every nonconstant input column is standardized with A/C mean and population SD, then clipped at±3 **as part of the frozen feature transform**, never by clipping a predicted rate or simulated count. SD<1e-8 gives an identically zero column and fixed-zero coefficient; persist full nominal and active counts. No intercept standardization. Clipping shares the same column definition/transformation across nested models and all score partitions; log-likelihood targets are unchanged. Rank, scales, selected units, native trial IDs, role cuts, masks, state warm-up/reset and all sensitivity configurations must be serialized before any later D request.

Wheel must be finite and strictly timestamp-ordered, in session seconds, with a documented event-driven encoder observation contract and a predecessor sample before epoch start. No interpolation through future observations. Compute backward sample-and-hold position and past increments only; record timestamp gaps/coverage and source semantics. If wheel/source coverage cannot support the nuisance design, the trial is not eligible for the primary comparison. Do not replace B1 with a wheel-free weak baseline. Wheel alone cannot control face/whisker/body/arousal. Source firstMovement times are retrospective and excluded as real-time predictors; no movement-locked secondary window is selected here.
