# Numerical and selection policy

NUMERICAL_POLICY.json is authoritative for numerical constants; FEATURE_MODELS.md supplies the exact objective and free coordinates. Bound projected gradient uses outward-gradient removal: at lower bound set g_i to0 only when g_i>0; at upper only when g_i<0; all other components retained. PG=||g_projected||∞. Fixed-zero constant-feature coefficients are not free coordinates. Optimizer success alone is insufficient: require finite loss/coefficients/scores/gradient, exact bounds, PG<=.001 and independent derivative gates. A failure cannot be cleared by a favorable checker step or success message. Report full/unprojected gradients, coordinates, call counts, objective and termination history.

Before Prompt3 real fitting require a reviewed production implementation gate covering every oracle in the owner's numerical contract: Poisson/factorial/exposure, normalization, equations/counts/nesting, analytic gradients vs independent AD and all fixed central differences, HMM conditional forward vs explicit state enumeration, pre-bin filtering, trial/gap resets, finite objectives, IID mixture identity, future-neural/behavior perturbation invariance and coefficient-bound signs. M1's small synthetic reference tests are specification evidence, not automatic certification of an unwritten production worker.

Analytic GLM gradients are Xᵀ(μ−y)/T+λβ; intercept has no ridge. D/S use exact differentiated forward recursion for the conditional objective including warm-up; independently implement AD over raw equations, not a wrapper around the analytic routine. Test initialization, a fixed intermediate synthetic point and endpoint; fixed steps{1e-4,1e-5,1e-6} must **all** pass scaled max-coordinate error<=1e-5, analytic/AD<=1e-8. Record absolute and relative block/coordinate errors. Central differences evaluate the mathematical extension of a box-constrained function at bounds; compare unconstrained derivatives before separately applying PG. Smooth nonfinite/unstable synthetic fixtures fail, no special step. For real endpoints require independent AD<=1e-5 at identical parameters/objective (fixed FD also attempted/reported); if FD fails its frozen gate, that fit is invalid even if explained by floating-point instability—no checker amendment in this protocol. No full Hessian/inverse requirement or optimizer rescue.

Each fit has L-BFGS-B maxiter2000,maxfun80000,maxls40,ftol1e-12,gtol1e-6, float64, and no retries. Linear/intercept/state/logit boxes and clipped inputs keep exponent arguments finite even at the largest U20 sensitivity (no output clipping). Constrained B0 has a closed-form solution; still evaluate objective/bounds/gradient. Constant predictors remain zero coefficients. Nonfinite source measurements stop that mouse; nonfinite fit/gradient or exhausted budget is preserved as NUMERICAL_FAIL. No alternate optimizer, altered box, seed replacement or extra start.

Initialization: each baseline/C intercept log[(sum A/C score counts+.5)/(TΔ)] projected to[-8,8], all other linear coefficients0. D/S copy this same *within-mouse* rate initialization (not development fitted coefficients for final mice); for each PCG64 seed11/23/37 set free state offsets to independent Uniform[-.05,.05]; π logits0; D transition free logit(i,j)=2I(i=j) minus2I(i=last reference state), representing diagonal preference relative to the reference column. S has no transition. No outcome-based restart. All3 D/S starts must pass; ensemble predictions uniformly mix pre-bin joint masses. The optimizer never observes B/E/D objective values.

Grid: B0 one fit; B1–B4 each3 λ; D2K×3λ×3seeds=18; C2rank×2τ×3λ=12; S2K×3λ×3seeds=18. Total61 A attempts/mouse, <=732 for12Development. B/C are one start. Every candidate uses the same admitted Development mice for its B-selection score; a candidate failing any required start/mouse is unavailable globally, not averaged on easier mice. If no valid B1 or B4 candidate remains, stop primary activation. Secondary family failures do not substitute another family or improve the primary cohort.

Selection uses mean of each mouse's B LL/Q; choose maximum across λ (and K/r/τ for D/C) with ties within1e-6 nats/unit-bin resolved by fewer nominal parameters, stronger λ, smaller K/r, then smaller τ, then lexical candidate ID. This is a fixed numerical tie rule, not a post-score one-SE change. Each baseline selects its own strongest B nuisance fit; B1 is not deliberately handicapped. S is selected across λ only at K=chosenD_K+1. Other S size attempts remain reported. No E-based tuning, A+B refit or individualized mouse hyperparameter selection. Freeze all winners and all failed attempts before E report and subsequent final preparation.

Final C uses those exact global policies and the same source/QC/A-C transformation algorithms, fit from C-only rates; no development coefficients reused. Main final fits/mouse=1B0+4baselines+1C+3D+3S=12, <=96 for8. No final hyperparameter search. Secondary family unavailable in Development remains unavailable Final. Primary fitting/scoring eligibility never excludes a mouse based on D/C superiority or D/E scores.

Sensitivity refits are limited to B0–B4 under the already selected λ for each baseline; no new model-family search. Exactly11 prespecified cases: units5,12,20;100ms bin;history250ms;stricterQC;rate thinning;saturation±10ms,±50ms;rich drift;anatomical boundary5. <=5fits×11cases×(12dev+8final)=1100 additional fits overall; only applicable cases run, all skipped capacity reasons retained. Main+sens ceiling=1928 fits across all later stages, no increase. Cases retain original animal roles/trial cuts and source identities; E/D effects never tune cases. Controls in STATISTICS_CONTROLS.md use frozen coefficients with <=4×999 surrogate replicate bundles/mouse, up to7model evaluations/bundle (<=28×999), **no null refits**. D/C/S have primary-configuration-only claims, not unexecuted sensitivity robustness. No scientific fitting happens in M1.
