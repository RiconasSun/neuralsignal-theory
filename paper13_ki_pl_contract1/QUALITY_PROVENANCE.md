# Quality provenance and proposed admission

This is a metadata/source inquiry, not physiological QC. The exact release is DANDI000473/0.230417.1502 (25 files, 25 animals, 9,408 curated-release unit identities). No actual eligible unit or animal has been certified.

The NWB `/units/quality` description names two ordered fields: `ISI violation, false positive rate`. It supplies no field-specific units, formula, refractory cutoff, denominator, exposure, estimator version, or exporter identity. Across all9,408 rows, column0 is integer-valued, range0–55,383; column1 ranges0–1. These observations do not establish that column0 is a count, a ratio or a particular contamination estimator. Column1's label suggests a rate/fraction, but its units and calculation remain unverified. Neither is used for proposed admission. The complete metadata schema and original values remain in the prior immutable header snapshots, not relabeled.

The [published methods](https://www.nature.com/articles/s41593-025-02190-z), sections Unit quality control and Extraction of spontaneous activity metrics, specify ISI-violation ratio<0.1, plausible waveform, presence ratio>0 and amplitude cutoff<0.1, plus epoch-spike sufficiency for the paper's memory metric. These are documented criteria, not a mapping from the two NWB fields. The memory-metric sufficiency rule is specific to that statistic and cannot certify predictive-model units. Source `pfcmap_unitloader.py`, pinned9ae52eddc47fbb590ef4e1b1949507334707a0f1, reads separate processed `quality/quality` and `waveform_quality` flags and tests equality to1; these are not the NWB two-column table.

The bounded direct-source search inspected the complete pinned pfcmap tree and the DANDI-linked Esr1_NPX_code tree at85187f32624da4cba9ccf9469183f93058a681b3. The latter exposes figure/analysis scripts, not an identified NWB quality exporter. Its README offers contact for questions. No upstream conversion version, field denominator or complete published-QC reconstruction was found. This closes the bounded search; no undocumented formula is substituted. Esr1 has no identified root code license; no implementation is imported from it. Existing pfcmap source is BSD2-Clause; released data/preprocessing attribution is retained (CC-BY4.0).

The new proposal uses an explicitly different **training-only operational physiological screen**, defined exactly in `results/initial/future_qc.json` and `PROPOSED_P13_V2.md`: finite strictly increasing times; at least50 training spikes,30 within-epoch adjacent ISIs and12 occupied training epochs; rate0.1–100Hz using all180 training seconds; fraction of within-epoch ISIs below1.5ms <=0.01. Duplicate/equal times fail. No ISI crosses a gap. No held-out rates, refractory fractions or test scores select units. This fraction is not the published ISI-violation/contamination ratio. Small finite counts limit purity interpretation; thresholds are operational and proposed before neural measurements, not biologically validated cutoffs. No uncertainty-based retrospective relaxation is allowed.

Only the first8 passing numeric PL unit IDs on the one probe are used. No waveform data are requested here, and no waveform-good/single-neuron purity claim is proposed. The target is prospectively screened **curated-release units**. Sensitivities use a stricter0.005 refractory fraction, the first4 of the8 units and a training-rate-stratified4-unit subset, with no replacement by test score. Failure to retain8mice in either preassigned role stops confirmation. Unknown historic quality remains a disclosed limitation even if new QC later passes.

Upstream full-record Kilosort/Phy curation, merges, splits, removal of duplicate spikes and saturated spikes precede the proposed split. Training-only downstream QC cannot make that retrospective preprocessing prospective, guarantee isolation, recover discarded events or exclude all artifacts. Selection may favor active/high-rate/stable clusters. The proposed generalization is within curated recording sessions and across this selected mouse cohort, not raw acquisition, all PL neurons, all behavioral states or an independent laboratory replication.
