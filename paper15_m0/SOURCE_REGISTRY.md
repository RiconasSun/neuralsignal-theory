# Source and license registry

The selected source is native IBL Brain Wide Map on the public `ibl-brain-wide-map-public` AWS bucket in us-east-1, licensed **CC BY 4.0** by the [official AWS registry](https://registry.opendata.aws/ibl-brain-wide-map/). Attribute International Brain Laboratory, Brain Wide Map, and retain the exact dataset UUID inventory when reusing the small derived counting examples. This right is verified for the native source; no DANDI license is borrowed.

The [official release documentation](https://docs.internationalbrainlab.org/notebooks_external/2025_data_release_brainwidemap.html) defines the Brainwidemap tag, 139 mice, 459 sessions and 699 insertions. These are global source denominators, not MOp cohort size. The metadata screen reuses the paired `2024_Q2_IBL_et_al_BWM` cluster/trial aggregate and `2023_12_bwm_release` insertion roster. Seven actual input hashes are in INPUT_PINS.json. The old frozen provider loading source commit is `118fc36cb3602934466ad2c6087c2b3b441f9f1f`; no mixed aggregate tags were used.

Native pilot sorting is explicitly `pykilosort/#2024-05-06#`; native trials are explicitly `#2025-03-03#`. Original file names, UUIDs, exact collections, byte sizes, modification times and S3 ETags were frozen in PILOT_FILE_FREEZE.json **before payload access**. FILE_RECEIPTS.json contains successful MD5/ETag checks and post-access SHA256s for 24 essential files, totaling 762,373,609 bytes. No raw AP/LFP signal, videos, waveforms or other mice's spikes were downloaded. AP `.meta` is a small source header, not raw electrophysiology.

The [official ONE/ALF reader documentation](https://docs.internationalbrainlab.org/notebooks_external/loading_spikesorting_data.html) and ONE-api 3.6.1 `one.remote.aws.s3_download_file` / `one.alf.io.load_file_content` were used. The former's public unsigned S3 backend is documented in its installed source. An anonymous Alyx session query returned 403; official public unsigned S3 resolved access without credentials, account setup or any substituted session. This is ordinary provider access recovery, not a change of dataset.

Clock/mapping methods are saved from the official ibllib repository at `3eced8ed26c2dfb6d149472c7ff2246f27d2bfb3` (IBLLIB_REVISION.json). `spikes.sync_spike_sorting` maps probe samples/fs through `sync_probes.apply_sync` into session seconds. The latter performs piecewise linear interpolation of a monotone probe-seconds/session-seconds table. `SpikeSortingLoader.merge_clusters` maps clusters through `channels[clusters.channels]`. The audit follows these definitions without rerunning extraction or sorting. `ephys_fpga.py` documents NI DAQ event and wheel extraction; the native trials and wheel are session-clock outputs. These source snapshots support interpretation, not a claim to have rerun historical provider extraction. Source code licensing remains that of the provider repository; snapshots are provenance material.

The [wheel documentation](https://docs.internationalbrainlab.org/notebooks_external/loading_wheel_data.html) describes irregular rotary encoder observations; these are available in both pilots. First-movement onsets are derived events, not direct neural mechanisms. Lick, pupil, whisker, face and whole-body movement are not established as complete here. No videos/pose payloads were accessed. Wheel alone leaves unmeasured movement confounding.

The [trial documentation](https://docs.internationalbrainlab.org/notebooks_external/loading_trials_data.html) describes native task tables and revisions. Pilot metadata comparisons show why old movement values/masks must not be silently transferred. CSH_ZAD_026 has 1,103 first-movement differences >1 microsecond (maximum 0.1562155 s); NYU-30 has 777 such differences (maximum 0.0015363 s), missingness and some trial-boundary differences. Native structural masks and native saturation intervals were used. The two sources of usable-trial counts are intentionally reported separately.

NYU-30 has 102 cluster-level anatomy differences between aggregate annotations and current native channel mapping; the complete table is saved. **The provider-good MOp cluster set is identical (22 units)**, although laminar/other-region labels change. CSH_ZAD_026's cluster UUID/QC/anatomy bridge agrees fully, including 84 good MOp units. No layer-specific inference is proposed. Remaining candidates need native annotation revalidation in M1 before admission.

Candidate B (DANDI 000010) and exceptional Candidate C were **not activated** because A supplies a useful M0 design and actual access. This follows the owner's conditional source order; it is not an assertion that B is unsuitable. No extra dataset was searched.
