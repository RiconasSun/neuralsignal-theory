# Paper 7 Frozen Protocol v0.1

Title:

```text
High-fidelity ACT/SIFT2 Structural Grounding of Reproducible Macroscopic Brain-State Transitions
```

## Research Question

Paper 5 found that a BedpostX-dyad structural proxy did not support subject-specific structural grounding. Paper 7 asks whether that negative result persists when `G_i` is constructed using a high-fidelity subject-specific tractography/connectome pipeline.

## Falsifiable Hypothesis

```text
P(S_(t+tau) | S_t, X_t, G_i) > P(S_(t+tau) | S_t, X_t)
```

where `G_i` is a subject-specific ACT/SIFT2 structural connectome, `S_t` is a macro fMRI brain state, and `X_t` contains task, time, run, and measured motion context.

## Dataset Lock

Primary candidate:

```text
HCP-YA 2025 only. Do not mix HCP-YA 2025 with 2017 S1200 processing.
```

Rationale: HCP-YA 2025 provides task-fMRI, diffusion MRI, T1w anatomy, and motion files. Current local Paper 5 data cache already contains authorized HCP-YA 2025 subject files.

## Structural Pipeline

Primary `G_i` must be generated by a high-fidelity tractography pipeline:

```text
dMRI -> MRtrix conversion -> response estimation -> MSMT-CSD -> FreeSurfer 5TT -> ACT -> iFOD2 -> SIFT2 -> tck2connectome
```

The current executable path uses MRtrix3 `5ttgen freesurfer` with HCP FreeSurfer
`aparc+aseg` to generate ACT-compatible 5TT images. This keeps P7 moving without
treating FSL as a hard blocker, but it also forbids the stronger
`gold-standard` label until a stricter segmentation path is separately frozen
and run.

Not allowed as final `G_i`:

```text
T1w-only anatomy
BedpostX dyads alone
group-average connectivity
previous Paper 5 proxy connectomes
```

## Primary Models

```text
M1: S_(t+tau) = F(S_t, X_t)
M2: S_(t+tau) = F(S_t, X_t, mean(G) S_t)
M3: S_(t+tau) = F(S_t, X_t, G_i S_t)
Mswap: S_(t+tau) = F(S_t, X_t, G_j S_t), j != i
Mrewire: S_(t+tau) = F(S_t, X_t, G_i^rewired S_t)
Mdistance: S_(t+tau) = F(S_t, X_t, G_distance S_t)
```

## Gates

Gate A:

```text
M3 > M1
```

Gate B:

```text
M3 > M2
```

Gate C:

```text
M3 > Mswap, Mrewire, Mdistance
```

Gate D:

```text
The direction survives a locked final subject holdout.
```

## Claim Boundary

Even if all gates pass, the strongest allowed claim is:

```text
High-fidelity subject-specific structural connectivity provides incremental constraints on macroscopic brain-state dynamics under the tested pipeline.
```

Forbidden claims:

```text
Brain structure determines cognition.
Structural mechanism is established.
NAP is structurally grounded.
CWP is validated.
Whole-brain mechanism is explained.
```
