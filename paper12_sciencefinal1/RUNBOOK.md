# Trusted-host final assessment

The owner instruction registered in the mission evidence prospectively authorizes
one frozen D evaluation after scientific/integrity preflight. Offline signing,
separate human verification, cryptographic entitlement and multi-principal release
are replaced. Their historical failures remain unchanged. The trusted operator and
machine administrator can access local artifacts. There is no independent custodian
or protection against a malicious administrator in this workflow.

No C fitting, model selection or scientific threshold amendment is implemented here.
The exact original production evaluator, C validator, math, metadata and model states
are reused. A new adapter authenticates the same envelopes and selects the same units
and trial masks. Run reservations prevent accidental duplicate execution and are not
an independently enforceable security ledger.

Order: registered hashes -> complete saved-C/provenance/access audit -> synthetic
transport/scoring/statistics tests -> complete 13-mouse/290-case synthetic D rehearsal
with 104x999 controls -> review -> single actual D run -> saved-result reproduction ->
manuscript and supplements -> review and archival Git closure.

Synthetic rehearsal uses real immutable C coefficients with artificial D counts at
the exact real D metadata shape. Original C provenance is never relabeled synthetic.
The frozen evaluator's return flag follows its C manifest; actual D lineage is
therefore recorded explicitly in run_receipt.json. Synthetic results cannot serve as
held-out biological results.

Real process interruptions preserve the reservation and every partial file. There is
no reset, entitlement regeneration, automatic scientific retry or second evaluation.
The process may continue across a UI interruption; a process crash stops the mission.
No partial scores may guide a repair or retuning.

The default PowerShell command only runs synthetic unit tests and recomputes the
statistics from saved public scalar results. It never decrypts protected data, fits a
model or reruns final assessment. Full protected evaluation is not a reproduction
default. Private source/delivery/C copies remain outside Git under ignored work/.
