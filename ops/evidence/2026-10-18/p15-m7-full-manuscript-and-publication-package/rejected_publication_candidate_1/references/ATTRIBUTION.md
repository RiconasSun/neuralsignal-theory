# Source attribution and bibliographic verification

The International Brain Laboratory supplied the original Brain Wide Map recordings, task data, native sorting and atlas mappings. Source data are CC BY 4.0 according to the official AWS registry, with the licence linked in the manuscript. This secondary analysis constructs new frozen features, models and derived result summaries; it does not imply endorsement by IBL, source authors, laboratories, publishers or institutions.

The actual native source is the AWS/ONE ALF release, not a DANDI conversion. Metadata tags are `2024_Q2_IBL_et_al_BWM` and `2023_12_bwm_release`; sorting is `pykilosort/#2024-05-06#`; trials are `#2025-03-03#`. Unrevisioned wheel/sync/header/saturation files are individually UUID/ETag/size/hash-pinned in the preserved manifests. Source snapshots retain provider-repository licensing; this package does not relabel them CC BY.

`verified_references.json` records twelve real references and the primary publication or official documentation used. Online verification occurred on 18 October 2026. Publisher challenge/403 responses were not called successful full-text fetches: original article PDFs, author manuscripts and original citation metadata supplied the stated bibliographic verification. No review article or search-result commentary is substituted for an original scientific source. No paper's findings are used as evidence for the present saved effect sizes.

The IBL release documentation's label is2025; access in2026 is not a new source version. Hemerik/Goeman was published online in2017 and appeared in TEST volume27 in2018. Names, titles, page ranges and identifiers are retained; a citation is not a claim of external review of the present manuscript.

Before external submission, scientific authors must verify authorship, affiliations, contributions, funding, competing interests, ethics/data-use requirements and all licence notices. These are explicit author-review placeholders, not invented facts.
