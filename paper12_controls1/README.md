Run from the repository root in native PowerShell:

```powershell

```

It never resets a ledger or accesses real C/D. The local verified Windows Python/runtime, NTFS ACL APIs and AppContainer launch permission are required. All failed attempts are retained. This command is independent of saved synthetic jobs.

```powershell

```

Private keys, custody envelopes, input counts, C rates/QC details, private prefit rosters, complete coefficient/scaler arrays and native job directories remain protected local artifacts excluded from Git.
