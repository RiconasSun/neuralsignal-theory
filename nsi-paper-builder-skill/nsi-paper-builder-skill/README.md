# NSI Paper Builder Skill

A portable skill for producing one of two NSI paper types:

- Method Paper
- Explanation Paper

Both share the A1–A10 reproducibility attachment standard.

## Main file

`SKILL.md`

## Templates

- `templates/method-paper.md`
- `templates/explanation-paper.md`
- `templates/a1-a10.md`

## Intended use

Give the skill a research idea, hypothesis, protocol, results package, or manuscript and ask it to:

- classify the paper
- create a skeleton
- create a full paper package
- draft from supplied evidence
- audit an existing paper

It must never fabricate experimental evidence.
